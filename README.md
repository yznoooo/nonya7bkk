# nonya7bk
موقع رومانسي بسيط باللغة العربية وجاهز للنشر على Vercel.

## الملفات
- `index.html`: محتوى الموقع.
- `style.css`: التصميم والألوان.
- `script.js`: الرسالة والأسئلة والعداد والتفاعلات.
- `assets/memories/`: صور الذكريات.

## ملاحظة العداد
يعرض عدد السنوات التقريبي منذ 2021 لأن تاريخ البداية الدقيق غير معروف.

## النشر
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح https://vercel.com وسجل الدخول باستخدام GitHub.
3. اختر Add New ثم Project.
4. استورد مستودع `nonya7bk`.
5. اترك إعدادات البناء كما هي واضغط Deploy.
